## ランダム親切行動スピナー

50種類の「今日できる親切」をCanvasルーレットでランダム提案し、達成チェック・連続日数ストリーク・今週の達成数を記録するポジティブチャレンジアプリ。

### 機能
- Canvas 2D描画のカラフルなルーレットホイール
- イージングカーブ付きスピンアニメーション
- 50種類の親切行動リスト（家族/友人/仕事/知らない人/SNS/自分自身の6カテゴリ）
- カテゴリフィルター機能
- 当選した行動のカード表示（詳細説明・難易度・所要時間）
- 完了チェックボタン → confettiアニメーション達成演出
- 今週の達成数・連続日数ストリーク・累計達成数の表示
- 今日の達成ログ表示
- localStorage による達成記録・ストリーク保存

### 技術
- 静的SPA（index.html単体）
- Tailwind CSS CDN
- Canvas 2D API によるホイール描画とスピンアニメーション
- requestAnimationFrame + cubic-bezier イージング
- localStorage 永続化
